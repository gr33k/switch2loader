STEP 2 OF 4

Prepare SmileBASIC

The upstream bootstrap must exist as NS2 in program slot 0. There is no published SmileBASIC download key.

  1. Open SmileBASIC 4.4.9 on system 23.0.1.
  2. If you have a wired USB keyboard, plug it into a USB-C hub connected to the Switch 2. In SmileBASIC Direct mode, type PRINT "USB OK" and press Enter. Continue only if USB OK appears. The hub and keyboard may vary in compatibility.
  3. Enter the pinned bootstrap.bas ↗ into editor slot 0, check it, then save it as NS2. A regular keyboard still requires manual entry of about 229 lines.
  4. For automatic typing, use a device that can itself act as a USB keyboard. A USB cable between Chrome and the console, a plain keyboard, or a VM cannot transmit a file into the editor.
Only have a Mac, cable, and Switch 2? There is no verified automatic route with those alone that leaves the Mac's security settings untouched. You can pause here; the LAN host is ready once NS2 is saved.
Research option: experimental Apple silicon Mac sender
  1. Get mac2jb ↗ and read its hardware and driver requirements before trying it.
  2. Its locally built USB gadget kernel extension is unsigned. Apple says personal kernel-extension testing on Apple silicon requires disabling SIP and using Permissive Security in Recovery; the published physical test did so. This changes Mac-wide protections and also requires Recovery to restore them. The wizard cannot do it for you.
  3. Only after the driver loads, test hello in an empty SmileBASIC editor. Continue to a full bootstrap transfer only if the text appears on the console.

This sender has been verified on one different Mac model, not on every Apple silicon Mac. See Apple's current kernel-extension guidance ↗.

What happens on the Switch 2?

01

Save the bootstrap once

Use a USB HID typing device to transfer upstream bootstrap.bas into SmileBASIC slot 0 and save it as NS2. The full game can keep it for later runs.

02

Start your local host

Run the companion on a computer or NAS reachable by the console. Select that host's actual IP, then press Start FS demo in its local wizard.

03

Enter short commands

Restart the console, open SmileBASIC Direct mode, then enter LOAD "TXT:NS2", RUN, and REMOVE NSR,&H60000000,&H3FFFFFFF separately. After the expected Out of memory message, enter the fresh V=START(...) line shown by the host.

04

Read the real result

Only the upstream host's verified completion counts as a pass. Restart the console when finished. This is an FS demo, not an EmuHub or emulator install.
